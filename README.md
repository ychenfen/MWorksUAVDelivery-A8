## 这次返工做了什么

初赛未晋级后，对已提交作品做了逐条复算，发现报告中三处结论无仿真支撑：

| 初赛结论 | 复算发现 |
|---|---|
| 三类场景 RMSE 经安全链降低 53%/52%/55% | 由基线 RMSE 乘硬编码系数 0.47/0.48/0.45 得到 |
| 阶跃超调降低 65.00% | 由基线超调乘 0.35 得到 |
| 180 组蒙特卡洛 P95 均低于 15% | 退化率算式中标称 RMSE 被约去，结果与控制器无关 |
| 集成四大安全模块形成协同闭环 | 四个模块从未被实例化，未进入控制回路 |
| 三机编队最大队形误差 0.861 m | 实现中不含控制律，是 0.12 s 延迟造成的几何偏差 |

全部作废并更正，相关代码与产物已移出交付路径。

在此基础上完成了两项实质工作：

**一、姿态超限的定量溯源。** 六组仿真累计 220 s 飞行中的全部 15° 超限采样点，都落在参考
轨迹不连续之后 0.06~0.08 s 内。进一步的单轴/多轴对照表明参考不连续是触发条件而非充分条件：
爬升场景 t=20 s 与 t=40 s 的单轴事件与 t=30 s 双轴事件的倾角指令完全等价（均饱和 9.500°、
速率约 560 °/s、上升 40 ms），姿态峰却是 11.92° / 17.39° / 11.92°。差别在指令之后——
双轴事件下两路内环同时饱和，X 型混控把作动量集中到一对对角旋翼（电机摆幅比 16.64 vs 1.05）。

**二、安全链接入并重跑验证。** 限速阈值由数据分布确定（正常飞行与跳变激励相差 20~40 倍，
取 60 °/s）。重跑结果：六个模型的 15° 超限累计时长全部归零。消融实验给出一个与预期相反的
结论——消除超限的是限速（ERG）而非障碍函数（CBF），且 ERG 开启后 CBF 累计修正量为 0、从未触发。

## 未达标项

预注册判据"ERG 不损精度（劣化 ≤3%）"在爬升场景**未达标**：接入限速后路径 RMSE 由
0.228024 m 升至 0.236546 m，劣化 3.74%，超出门槛 0.74 个百分点。

该判据写定时以 `metrics_summary.json` 的 0.23289 m 为基准，按那个值计算劣化仅 +1.57%、
看似达标；重跑证实该文件已过期。**基准修正不构成回头放宽判据的理由**，此项按未达标记录。

判据六（闭环鲁棒性）尚未开展，本作品目前不对系统鲁棒性作任何定量声明。

## 复算方式

报告中的机理类结论均可由 `03_Simulation_Results/` 的 CSV 直接复现：

```bash
cd 06_Rework_SafetyChain/analysis
python3.11 quantify_jump.py        # 参考不连续对 RMSE 的贡献
python3.11 recheck_mechanism.py    # 单轴/双轴对照与混控分配
python3.11 pick_rate.py            # 限速阈值的数据依据
python3.11 verify_formation.py     # 编队控制律三项测试
python3.11 make_figures.py         # 重新生成全部配图
```

需要 Python 3.11 与 numpy / pandas / scipy / matplotlib。
